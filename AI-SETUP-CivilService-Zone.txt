Nirvix AI — AI Assistant Setup
======================================

The uploaded website source already contains:
- A Nirvix AI AI Help chat button and chat panel in index.html
- Text question submission to POST /api/ai/ask
- Microphone speech-to-text (browser support required)
- A “Listen to answer” button using the browser's speech synthesis
- A server-side OpenAI API integration in server.js
- Multi-language behaviour instructed by the server prompt

IMPORTANT: the AI will not answer on the live website until the OpenAI API key is configured on the server.
Do NOT put the API key in index.html or any browser JavaScript.

Render setup:
1. Open the Nirvix AI service in Render.
2. Open Environment.
3. Add environment variable:
   OPENAI_API_KEY = your OpenAI API key
4. Optional:
   OPENAI_MODEL = gpt-4.1-mini
5. Save changes and deploy/redeploy the service.
6. Open https://YOUR-DOMAIN/api/health
   Check that "aiConfigured" is true.
7. Open the website, tap "AI Help", and ask a test question.

API billing/credits may be required by the OpenAI account. ChatGPT subscription and API billing are separate.
The /api/health endpoint reports configuration, not proof that a real AI answer has succeeded.
Test with a real question after deployment.

Voice notes:
- The microphone button uses the browser's speech recognition feature, which is not available in every browser/device.
- The “Listen to answer” button uses browser text-to-speech. It is not a live, natural voice conversation like a phone call.
- HTTPS is required for many browser microphone features.

Accuracy note:
AI can make mistakes. For RCC/structural design, safety, legal, medical or financial matters, verify important answers with a qualified professional and trusted sources.

Included source files are the files supplied for this update. This package does not include any API key or private credentials.
