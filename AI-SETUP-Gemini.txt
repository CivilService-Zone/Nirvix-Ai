Nirvix Ai — Gemini AI Setup
===========================

The website now supports Google's Gemini API on the server. The Gemini key must never be placed in index.html or browser JavaScript.

Render setup:
1. Open the Nirvix Ai service in Render.
2. Open Environment.
3. Add GEMINI_API_KEY with your key from Google AI Studio.
4. Optional: add GEMINI_MODEL=gemini-2.5-flash
5. Save changes and redeploy.
6. Open /api/health on your domain and check aiConfigured=true and aiProvider=Gemini.
7. Open AI Help and ask a test question.

If GEMINI_API_KEY is not set, the server can still use the previous OpenAI configuration if OPENAI_API_KEY is configured.

When AI is not configured or a request fails, the app displays:
